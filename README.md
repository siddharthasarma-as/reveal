# NESFIC 2026 — Problem Statement Reveal

Cinematic reveal for the North-East SEVA FIRST Innovation Challenge 2026.

## Sequence

1. Countdown from 5 to 0.
2. Ribbon and mouse-controlled scissors.
3. Ribbon opens like curtains.
4. NESFIC logo appears alone on a full-screen screen for 2 seconds.
5. Logo disappears.
6. Problem-statement box opens.
7. 24 selected problem statements animate into a 5×5 layout with the NESFIC logo at the centre.
